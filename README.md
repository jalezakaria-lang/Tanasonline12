# 📄 Generator Surat & SPD Otomatis

Aplikasi web berbasis JavaScript (Vanilla JS) & Tailwind CSS untuk membuat Surat Tugas dan Surat Perjalanan Dinas (SPD) secara otomatis dan siap cetak.

## ✨ Fitur Utama
- **Landing Page & Navigation**: Halaman depan interaktif dengan sistem Single Page Application (SPA).
- **Live Preview Real-time**: Pratinjau dokumen menyesuaikan isi form secara langsung.
- **Multi-page PDF Export**: Ekspor dokumen multi-halaman (Surat Tugas + Form SPD) ke format PDF.
- **Responsive Layout**: Tampilan optimal untuk perangkat desktop maupun mobile.
